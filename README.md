# Bloderyn's Codex

This site uses Vite, React, Mantine, pnpm, and Biome.

## Start developing

From the repository root, install dependencies and start the Vite server:

```sh
pnpm install
pnpm dev
```

Open the local URL printed in the terminal, usually `http://localhost:5173/`.
The page is rendered from `my-links-page/src/App.jsx`; link data is at the top
of that file and styles live in `my-links-page/src/styles/`.

## Build and code quality

```sh
pnpm build
pnpm preview
pnpm lint
pnpm check
```

The production build is written to `dist/`.
